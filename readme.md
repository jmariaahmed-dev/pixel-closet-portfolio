# Maria’s Pixel Closet – Web Development Studio Portfolio

This repository contains my portfolio website for **Coding 3 – Web Development Studio (Creative Computing, Year 2)**.

The project presents weekly creative coding tasks (Weeks 1–10) as part of a single, accessible, cross-platform portfolio website.

---

## Live Website

🔗 **Portfolio website:**  https://jmariaahmed-dev.github.io/pixel-closet-portfolio/
